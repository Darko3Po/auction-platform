# Auction platform

### FEATURES:

### AUTHENTICATION:

- Authentication system

### USERS:

- Sign up
- Log in
- Log Out

### AUCTIONS

- Post auction product
- Option buy now 
- Option bidding


### Automation

- A command that finds auctions that have expired
- End Auction Job system that finds the highest bid after the auctions have ended and places the order in the orders
- User notifications about winning the auction.

### TECHNOLOGIES USED:    

PHP, Laravel, MySQL, JavaScript, TailwindCSS


##  Installation

- Clone repo
```
https://github.com/Darko3Po/auction-platform.git
```

- Copy the .env.example file to .env

- Open terminal
```
php artisan migrate
```
```
php artisan serve
```
